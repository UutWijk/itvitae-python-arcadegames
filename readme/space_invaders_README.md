Space Invaders

Dit GitHub project is een poging tot het nabootsen van de klassieke arcade game Space Invaders in Python, 
met gebruik van de pygame community edition package.

Het spel moet op dit moment nog geopend worden via een python command in de terminal, maar de bedoeling is
dat deze onderdeel wordt van een groter programma met andere spellen, die functioneert als arcade kast.
