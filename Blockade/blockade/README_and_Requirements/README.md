# BLOCKADE
An arcade game from the '70's recreated in pygame

### Features:
* Simple arcade-style graphics.
* Recreation of retro gameplay.

## Requriements:
See requirements.txt

### How To Play:
* When the game starts, press any key to begin.
* The 'W A S D' keys move player 1 up, left, down, right respectively.
* You will play untill someone has 3 wins, draws are possible.
* When a player has 3 wins, a prompt will appear on screen asking if you want to try again: use the 'Z' key to reset the game.

### Project Structure:
* Main.py runs the game and handles game logic.
* Player.py makes the player class that gets used in the game.
* Sound.py handles the soundeffects, the assets for this are stored in the asset folder.
