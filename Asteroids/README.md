# Python Asteroids (pygame-ce)
A classic implementation of Asteroids (1979) built with Python 3.14 and pygame-ce

## Requirements
- Python 3.14 and above installed
- pygame-ce module installed
- pip (Python package manager)

## How to Play
- Joystick          turn left/right
- A:                shoot
- B:                warp mode (Not implemented)


## Project Structure
- asteroids.py:     game logic class (instance of State)
- player.py         player class with movement logic
- obstacle.py:      asteroid class
- bullet.py:        bullet class
- ufo.py            ufo class
- sounds.py:        game sound effects class
